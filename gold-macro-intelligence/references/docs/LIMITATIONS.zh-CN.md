# 验证状态与使用限制

[English](LIMITATIONS.md) · [返回首页](../README.zh-CN.md)

**项目定位：研究工具。真实交易策略资格：`NO_GO / NO_VALIDATED_SIGNAL`。** 能安装成功、单元测试通过，只说明指定软件行为符合测试预期，不代表黄金投资一定赚钱。

## 已完成的软件能力

GMI 具备确定性计算、数据输入校验、CFTC 报告解析、历史回撤/回补、宏观事件对齐、因子研究接口、Walk-Forward 测试框架、仓位风险检查及合成数据一致性检验。v1.0 对外可宣称的通过项，应以最终干净环境中的真实测试记录为准。

## 还没有得到证明的能力

- 完整真实交易策略的严格 Point-in-Time 真实性：多个数据源的首次发布时间、历史版本和修订证据仍不完整。
- 六个模块的真实长历史全面覆盖：央行、ETF、流动性和期权并非都有免费可直接调用的完整数据。
- 所有历史时期的可执行黄金成交价格：月均价是研究参考值，不是实际成交价。
- 综合信号在独立样本外的统计显著性、稳定性及真实成本后的获利能力。
- 所有 Agent 宿主的自动兼容或运行代码权限。

缺失的因子不能机械打零分；数据修订可能改变事后结论；CFTC 分类持仓不能识别具体交易者的所有交易动机；央行储备吨数变化不直接等于现金买卖；因风控而减仓不是宏观看空模型的预测。

## 合理使用方式

把输出作为整理问题、复核历史行情及识别市场变化的依据。真实资金仓位还需要独立核验数据、交易标的自身的流动性、风险承受能力和资金使用要求。GMI 不连接券商，也不自动调整账户持仓。

能否完整重现报告取决于合法获得的输入文件、真实发布时间、版本与转换程序。上述证据不全时，系统应直接显示限制，而不是生成没有依据的高置信度结论。
