# Security and responsible disclosure

[简体中文](SECURITY.zh-CN.md) · [Home](README.md)

GMI does not require broker credentials and must not place orders. Keep API keys, portfolios and downloaded third-party data outside the public repository. Review a proposed data connector for remote requests and license terms before enabling it.

**Do not post a security vulnerability, private token or personal portfolio in a public issue.** If GitHub's private vulnerability reporting is enabled for this repository, use that channel. Otherwise contact the repository maintainer through an available non-public channel shown on the maintainer's GitHub profile. No private address is invented in this file.

If a security issue affects published code, provide the affected version, reproduction steps and impact privately where possible. No response-time guarantee is promised.
